# JuziGenius 🧠✍️
**JuziGenius** (句子Genius) is a hardcore Mandarin Chinese writing tutor. 

Unlike most apps, JuziGenius uses a "Zero-Help" philosophy:
- **Handwriting Only:** No Pinyin input or predictive text.
- **Strict Stroke Order:** Powered by Hanzi Writer.
- **Generative Sentences:** Uses Gemini AI to build infinite challenges using ONLY your unlocked vocabulary.
- **Linguistic Tutor:** An AI Professor that validates your unique sentence structures.

## Setup
1. Clone the repo.
2. Rename `config.py.example` to `config.py` and add your Gemini API Key.
3. Run `python3 generate_batch.py` to seed your brain.
